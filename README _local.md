## 📌 简介

![intro](.\image\intro.png)

“终常小窗”是一款专为《明日方舟：终末地》玩家打造的轻量级、免安装桌面日常辅助工具。
它能以极简的无边框悬浮窗形式贴合在游戏画面上，帮助你逐条追踪日常任务进度。告别繁琐的记忆和遗漏，让你以最高效的流程清理日常，节约宝贵的时间。

## ✨ 核心功能

* **定制鼠标与窗口半透明：** 窗口采用终末地样式的定制鼠标，增加沉浸感；且默认鼠标不移入时保持一定的透明度，透明度可在配置文件中自行调整。

  ![cursor and transparency](.\image\cursor and transparency.gif)
* **极简悬浮，随心拖拽：** 无边框设计，支持在任意位置拖动窗口，支持在右下角调整窗口大小。绝不遮挡游戏关键视野。窗口的大小和位置将在每次 拖拽 / 缩放 后自动保存。

  ![drag](.\image\drag.gif)

  ![zoom](.\image\zoom.gif)
* **自动聚焦游戏：** 鼠标指针移出后自动聚焦到游戏（锁定进程：Endfield.exe），无需再在游戏中点击，增加沉浸感。

  ![auto focus](.\image\auto focus.gif)
* **灵活定制任务：** 纯文本 `TODO.txt` 驱动，人人皆可轻松编辑，定制专属的日常清本路线。
* **一键启动游戏：** 绑定游戏路径，并在设置中勾选“自动启动游戏”后，打开小窗即刻自动拉起游戏，快人一步。

![settings](.\image\settings.png)

* **日常计时器：** 可以选择性开启计时功能，完成后自动结算耗时，看看今天是不是比昨天“凹”得更快！

![timing_1](.\image\timing_1.png)

![timing_2](.\image\timing_2.png)

* **绿色免安装：** 纯粹的本地单文件工具，不写注册表，随用随开，删文件夹即彻底卸载。

## 🚀 快速上手

### 1. 运行程序
本软件为绿色版，解压后双击运行 **`Endfield Task Overlay.exe`** 即可。

### 2. 界面按钮说明
主界面右上角提供了一排快捷操作按钮：
* `[ ⏱ ]` **开始计时：** 点击后开始隐形计时。完成最后一步任务时，会为你展示本次清日常的总耗时。
* `[ ✏ ]` **编辑任务：** 一键打开 `TODO.txt` 进行任务修改。
* `[ ⚙ ]` **设置：** 原位打开设置面板，可在此配置“是否置顶”、“是否自动启动游戏”以及修改“游戏绝对路径”。
* `[ ? ]` **帮助：** 查看此说明文档（将使用你的默认浏览器打开 README.pdf）。
* `[ ✕ ]` **关闭：** 退出程序（完成所有任务后，程序也会自动倒计时 5 秒退出）。

### 3. 调整窗口与记忆
* **移动：** 鼠标按住窗口内的**任意空白处**即可拖动。
* **缩放：** 鼠标按住窗口**右下角**进行拖拽，可等比例放大/缩小窗口和文字。
* **记忆：** 你的窗口位置和大小会自动保存在同目录的 `settings.json` 中，下次打开依然是你最舒适的配置。

## 📝 如何编写 TODO.txt

软件会读取同目录下的 `TODO.txt` 文件作为任务来源。
**书写规则：**
1. 每一行代表一个单独的任务步骤。
2. 遇到空行会自动跳过。
3. 当程序读取到包含 `--- 可选内容` 这一行时，将**停止读取**后续内容（你可以在这行下面做备忘录，它们不会显示在主界面的任务流中）。

**推荐模板参考：**
```txt
祝您在塔卫二的旅途一切顺利，管理员！
帝江号——收取基建产物 [I]
帝江号——送礼物，造装备，拿日活跃奖励
据点管理——换调度券 [Y]
物资调度——稳定需求和弹性需求物资 [Y]
好友——进行情报交流和生产助力
活动——打活动（如果有）[F7]
行动手册——清理智 [F8]
仓储节点——送货 [Y]
信用交易所——清信用 [F5]
环境监测终端——拍照任务（如果有）[Y]
采集提示——收集地图中的菌、石、叶（如果有） [M]
亲一口洛茜
帝江号——回到干员联络台处

--- 可选内容（不全，您可以自行添加） ---

此处的内容将不会出现在小窗中，如果您希望每日处理这类事务，请手动将其添加到上面

```

## 🛠️ 常见问题 (FAQ)

**Q1: 窗口太小/太大怎么办？**
直接将鼠标光标移动到软件界面的最右下角，光标变为缩放箭头后，按住左键拖拽即可。

**Q2: 为什么勾选了“自动启动游戏”，但打开小窗时游戏没反应？**
请点击 `[ ⚙ ]` 设置按钮，检查“游戏路径”是否填写正确。你需要填写游戏启动文件（`.exe`）的**绝对路径**。例如：`C:/Program Files/Hypergryph Launcher/games/Endfield Game/Endfield.exe`。直接从文件属性中复制粘贴即可，程序会自动处理斜杠格式。

**Q3: 勾选“自动启动游戏”后可能存在的卡在加载界面或游戏版本无法更新的问题？**
本软件采用的启动原理是直接找到游戏本体的可执行文件启动。如果卡在加载界面，请尝试使用鹰角启动器启动；如果需要进行游戏大版本更新（如 `v1.0 零号委托` 到 `v1.1 新潮起，故渊离`），请务必到鹰角启动器中进行更新。

**Q4: 在配置文件 `settings.json` 中修改配置按下确定后却与修改不符的问题？**
![settings priority](.\image\settings priority.png)

当在设置子窗口按下“确定”按钮时，设置窗口中有的项目将优先遵循设置窗口（置顶、自启动、路径、位置）；仅设置窗口中不存在的项目将遵循配置文件（缩放、透明度）。简单来说就是——设置窗口优先。
